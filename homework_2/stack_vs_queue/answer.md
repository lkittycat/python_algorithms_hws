## Объяснение решения


для этого есть класс Node, у него value это значение, а next — ссылка на след узел. у последнего узла next равен None.

в стеке head указывает на вершину.

при push создаем новый узел, его next направляем на старую вершину, потом head переносим на новый узел;

при pop сначала сохраняем значение вершины, потом передвигаем head на следующий узел и возвращаем сохраненное значение;

peek просто возвращает значение вершины, ничего не удаляя

в очереди храним две ссылки: head на первый узел и tail на последний

при enqueue добавляем новый узел после tail и переносим tail на него. если очередь была пустая, head тоже указывает на новый узел;

при dequeue сохраняем значение первого узла и передвигаем head на следующий. если узлов больше нет, tail тоже делаем None

peek у очереди возвращает значение первого узла без удаления.


## Оценка сложности

пусть в структуре n элементов;

push, pop и peek у стека работают за O(1);

enqueue, dequeue и peek у очереди тоже работают за O(1);

мы не обходим список,  только читаем значение и меняем несколько ссылок. и так как тэйл есть типа не ищем конец

память  O(n), потому что на каждый элемент создаем отдельный узел. здесь считаем память узлов и ссылок, без размера самих переданных объектов


## Визуализация

стрелки показывают направление next. начало каждой цепочки  head

стек:

сначала пусто, head = None;

push(1): 1 -> None;

push(2): 2 -> 1 -> None;

pop() возвращает 2, останется 1 -> None;

push(3): 3 -> 1 -> None;

push(4): 4 -> 3 -> 1 -> None;

peek() возвращает 4,

pop() возвращает 4, остается 3 -> 1 -> None;

pop() возвращает 3, останется 1 -> None;

pop() возвращает 1, теперь head = None;

еще один pop() вызовет IndexError;

push(5): снова можно добавлять, получаем 5 -> None.




очередь:

сначала head = None и tail = None;

enqueue(1): 1 -> None, head и tail указывают на узел 1;

enqueue(2): 1 -> 2 -> None, tail теперь на узле 2;

dequeue() возвращает 1, остается 2 -> None;

enqueue(3): 2 -> 3 -> None, tail на узле 3;

enqueue(4): 2 -> 3 -> 4 -> None, tail на узле 4;

peek() возвращает 2, очередь не меняется;

dequeue() возвращает 2, остается 3 -> 4 -> None;

dequeue() возвращает 3, остается 4 -> None;

dequeue() возвращает 4, теперь head = None и tail = None;

еще один dequeue() даст IndexError;

enqueue(5): получаем 5 -> None, обе ссылки указывают на узел 5.
