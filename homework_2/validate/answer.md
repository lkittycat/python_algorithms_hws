## Объяснение решения

числа добавляются строго в порядке pushed. извлекаем только вершину и только если это следующее нужное число, поэтому уже полученная часть всегда совпадает с началом popped;

если вершина совпала, можно сразу ее снять: она как раз должна выйти следующей. добавление новых чисел поверх нее не помогает;

если вершина не совпала, снимать ее нельзя, иначе нарушим порядок popped. остается добавить следующее число из pushed;

если числа для добавления закончились, а нужное число все еще закрыто другим, то уже все, получить popped невозможно((

## Оценка сложности

пусть n  кол-во чисел в pushed;

каждое число добавляем в стек один раз и удаляем максимум один раз; хотя while находится внутри for, суммарно удалений будет не больше n, а не n на каждой итерации;

сложность по времени O(n). append у листа работает за O(1) амортизированно, то есть отдельное добавление может потребовать расширения списка, но все n добавлений вместе занимают O(n)


по памяти O(n), потому что в стеке могут одновременно оказаться все числа. например, если popped идет в обратном порядке.

## Визуализация

pushed = [1, 2, 3, 4, 5], popped = [1, 3, 5, 4, 2];

сначала stack = [], j = 0, ждем 1;

добавляем 1: [1]. вершина совпала, достаем 1. стек [], j = 1, теперь ждем 3;

добавляем 2: [2]. ждем 3, поэтому 2 не трогаем;

добавляем 3: [2, 3]. достаем 3, остается [2], j = 2,  ждем 5;

добавляем 4: [2, 4]. вершина не 5, ничего не достаем;

добавляем 5: [2, 4, 5]. достаем 5, остается [2, 4], j = 3, ждем 4;

4 уже на вершине, достаем ее. остается [2], j = 4, ждем 2;

достаем 2, стек пустой, j = 5;

j равен длине popped, ответ true. после добавления 5 цикл извлек : 5, 4, 2.

пример, когда не получится:

pushed = [1, 2, 3], popped = [3, 1, 2];

ждем 3, поэтому по очереди добавляем 1, 2 и 3, получаем [1, 2, 3];

достаем 3, остается [1, 2], j = 1;

теперь нужна 1, но сверху 2. добавлять больше нечего, а достать 1 через 2 нельзя;

j = 1, длина popped равна 3, ответ false.
