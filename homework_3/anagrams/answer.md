## Объяснение решения


функция group_anagrams в algo.py проходит по словам и для каждого считает буквы в словаре counts;

например, у eat, tea и ate буквы e, a и t встречаются по одному разу;

в списке groups храним группы слов, а в letters — словарь с количеством букв для каждой группы. одинаковый индекс связывает группу и ее счетчики;

сравниваем counts со словарями в letters через ==. порядок записи букв не важен, сравниваются сами буквы и их количества;

если нашли совпадение, добавляем слово в эту группу и ставим found = True. если ни одна группа не подошла, добавляем новую группу [word] и ее словарь counts. сортировку и множества не используем;

в конце возвращаем список всех групп. сторонних библиотек нет, исходный список не меняется;

порядок групп в условии не задан, поэтому оставляем порядок первого появления групп, а внутри — порядок слов на входе. из-за этого ответ может выглядеть иначе, чем в примере, но группы будут теми же;

регистр учитывается: A и a считаем разными символами. пустые строки попадают в одну группу, повторяющиеся слова сохраняются.

## Почему работает

если два слова — анаграммы, количество каждой буквы у них одинаковое. их словари счетчиков равны, поэтому слова попадут в одну группу;

если словари счетчиков равны, значит, совпадают и буквы, и количество каждой буквы. поэтому слова в одной группе действительно анаграммы;

каждое слово добавляем ровно один раз, поэтому ничего не теряем и не добавляем лишних слов.

## Оценка сложности

пусть n — количество слов, L — суммарное количество символов, d — максимальное количество разных букв в одном слове;

подсчет букв во всех словах занимает O(n + L). для каждого слова можем проверить до n групп. сравнение двух словарей занимает до O(d + 1);

верхняя оценка времени O(L + n² * (d + 1)) при обычной работе хеш-таблиц. этот вариант медленнее, потому что перебирает группы, зато использует прямое сравнение словарей;

поиск и запись по ключу словаря считаем в среднем за O(1), без худшего случая массовых коллизий;

дополнительная память O(n + L): храним группы, счетчики и ссылки на слова. сами исходные слова не копируются.

## Визуализация

слова: ["eat", "tea", "tan", "ate", "nat", "bat"];

eat: e — 1, a — 1, t — 1, создаем группу ["eat"];

tea: те же буквы по одному разу, группа становится ["eat", "tea"];

tan: t — 1, a — 1, n — 1, создаем отдельную группу ["tan"];

ate: счетчики совпадают с eat, первая группа теперь ["eat", "tea", "ate"];

nat: счетчики совпадают с tan, вторая группа теперь ["tan", "nat"];

bat: b — 1, a — 1, t — 1, создаем третью группу ["bat"];

возвращаем [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]. это те же группы, что в условии, только в другом порядке.
