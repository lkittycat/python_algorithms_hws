## Объяснение решения

каждый узел Node хранит значение value и ссылки на левого и правого ребенка: left и right;

BST хранит корень root. в пустом дереве root равен None;

для каждого узла все значения в левом поддереве меньше его значения, а в правом больше;

insert начинает с корня. если новое значение меньше текущего, идем влево, если больше - вправо. когда нужная ссылка пустая, создаем там узел. так сохраняется свойство BST;

если значение уже есть, ничего не добавляем;

каждый обход создает список result и рекурсивно обходит дерево. на пустом узле возвращаемся, а значение добавляем через append;

порядок обходов как в [условии](https://en.wikipedia.org/wiki/Tree_traversal):

preorder: узел, левое поддерево, правое поддерево;

inorder: левое поддерево, узел, правое поддерево;

postorder: левое поддерево, правое поддерево, узел;

reverse preorder: узел, правое поддерево, левое поддерево;

reverse inorder: правое поддерево, узел, левое поддерево;

reverse postorder: правое поддерево, левое поддерево, узел;

в reverse обходах меняем местами левое и правое поддеревья на каждом шаге;

каждый метод возвращает список значений. для пустого дерева получаем [].

## Оценка сложности

пусть n - количество узлов, h - высота дерева;

вставка занимает O(h) времени и O(1) дополнительной памяти. для сбалансированного дерева это O(log n) времени, в худшем случае O(n), если дерево вытянулось в цепочку. балансировку здесь не делаем;

каждый обход занимает O(n) времени, тк посещаем каждый узел один раз;

список результата занимает O(n) памяти, стек рекурсии - O(h). всего O(n) дополнительной памяти;

само дерево занимает O(n) памяти.

## Визуализация

вставляем значения 4, 2, 6, 1, 3, 5, 7;

```text
    4
   / \
  2   6
 / \ / \
1  3 5  7
```

4 становится корнем, 2 идет влево от 4, а 6 вправо;

1 и 3 становятся левым и правым детьми 2, а 5 и 7 - левым и правым детьми 6;

preorder: [4, 2, 1, 3, 6, 5, 7];

inorder: [1, 2, 3, 4, 5, 6, 7];

postorder: [1, 3, 2, 5, 7, 6, 4];

reverse preorder: [4, 6, 7, 5, 2, 3, 1];

reverse inorder: [7, 6, 5, 4, 3, 2, 1];

reverse postorder: [7, 5, 6, 3, 1, 2, 4].
