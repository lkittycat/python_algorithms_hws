## Объяснение решения

строим перестановку по одному элементу, используя backtracking;

в current храним текущий путь, в used отмечаем занятые индексы исходного массива

на каждом уровне перебираем индексы слева направо. если индекс еще не использован, отмечаем его, добавляем число в current и вызываем backtrack

когда длина пути равна длине массива, получена полная перестановка. сохраняем копию пути, иначе дальнейшие изменения current поменяли бы ответ;

после возврата удаляем последнее число и освобождаем индекс. так восстанавливаем состояние перед проверкой следующего варианта

каждая перестановка индексов соответствует ровно одному пути от корня к листу. перебираем все свободные индексы, поэтому ни один вариант не пропускаем

исходный массив не меняем. для пустого массива возвращаем [[]]: существует одна пустая перестановка

индексы считаем разными даже при одинаковых значениях. поэтому для [1, 1] ответ [[1, 1], [1, 1]]. для различных чисел, как в условии, все результаты различны;

backtrack обернула в tracer из первой задачи. аргумент current позволяет видеть уже выбранные числа при входе в каждый вызов. в листе возвращаем копию перестановки для наглядного вывода, промежуточные вызовы возвращают None, а полный ответ накапливается в result


## Оценка сложности

пусть n - длина массива, числа имеют постоянный размер;

существует n! перестановок, каждую копируем за O(n). итоговое время O(n · n!) для n >= 1; перебор свободных индексов укладывается в эту оценку;

результат занимает O(n · n!) памяти. без трассировки дополнительная рабочая память O(n): путь, used и стек рекурсии;

с включенным tracer вывод также занимает O(n · n!) времени: на листьях печатаем путь длины n и отступ глубины n. в активных кадрах декоратора хранятся строки аргументов и отступов, поэтому рабочая память с трассировкой O(n²), помимо результата. напечатанные строки сама функция не накапливает;

для n = 0 время и память O(1). глубина рекурсии O(n)

## Визуализация

дерево выбора для [1, 2, 3]:

```text
[]
├── [1]
│   ├── [1, 2]
│   │   └── [1, 2, 3]
│   └── [1, 3]
│       └── [1, 3, 2]
├── [2]
│   ├── [2, 1]
│   │   └── [2, 1, 3]
│   └── [2, 3]
│       └── [2, 3, 1]
└── [3]
    ├── [3, 1]
    │   └── [3, 1, 2]
    └── [3, 2]
        └── [3, 2, 1]
```

пример полного вывода стека для [1, 2]:

```text
-> backtrack([])
    -> backtrack([1])
        -> backtrack([1, 2])
        <- backtrack = [1, 2]
    <- backtrack = None
    -> backtrack([2])
        -> backtrack([2, 1])
        <- backtrack = [2, 1]
    <- backtrack = None
<- backtrack = None
```

сначала получаем [1, 2], возвращаемся к пустому пути, затем получаем [2, 1]. результат [[1, 2], [2, 1]];
